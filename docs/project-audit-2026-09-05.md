保留的限制：

- Hash 路由仍保留，便于兼容已有分享链接，并使分享参数不随 HTTP 请求发送。Google 不建议用 fragment 加载可独立索引的页面，因此本次没有把结果、设置和关于页宣称为可独立收录页面；无脚本简介也不等于服务端渲染。若要提升关于页的独立收录，需要另行设计真实 URL / 预渲染，并保持分享数据的隐私边界。[Google JavaScript SEO 文档](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)
- 汉字资料按需分块仍约 1.44 MB（gzip 448 KB），构建仍提示该分块超过 500 KB。它不阻塞首页，但首次使用汉字起卦需要下载；为保留完整字库功能，本次未删减数据，也未隐藏构建警告。
- 本次验证的是本地行为和资源发现方式，未采集线上用户的 Core Web Vitals，没有宣称 LCP、INP 或搜索排名的量化提升。字体预加载采用标准资源提示方式。[web.dev 字体优化说明](https://web.dev/learn/performance/optimize-web-fonts)
